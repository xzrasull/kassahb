# ШтрихКасса — версия на Supabase + Vercel

Тот же интерфейс кассы (сканирование штрихкода, корзина, оттенки, история чеков),
но данные теперь лежат в вашей собственной базе Postgres на Supabase, а сам сайт
можно развернуть на Vercel — без ограничений и без привязки к Claude.

## Файлы

- `index.html` — вся касса (один файл, без сборки).
- `config.js` — сюда вписываете 2 ключа от своего проекта Supabase.
- `schema.sql` — SQL-скрипт создания таблиц (товары, чеки, настройки).

## Шаг 1. Создать проект Supabase (бесплатно)

1. Зайдите на [supabase.com](https://supabase.com) → **Start your project** → войдите
   через GitHub/Google.
2. **New project** → придумайте имя, задайте пароль базы (сохраните его, дальше
   он не понадобится, но пусть будет записан) → выберите ближайший регион → Create.
   Подождите ~2 минуты, пока проект поднимется.

## Шаг 2. Создать таблицы

1. В проекте слева откройте **SQL Editor** → **New query**.
2. Откройте файл `schema.sql` из этой папки, скопируйте весь текст, вставьте
   в редактор и нажмите **Run**.
3. Должно появиться "Success. No rows returned" — значит таблицы `products`,
   `receipts`, `settings` созданы, и доступ к ним ограничен только вошедшими
   пользователями (Row Level Security).

## Шаг 3. Создать пользователя (вход в кассу)

Это единственный логин/пароль, под которым будет заходить касса (можно
использовать его на всех кассирах — они на одном компьютере, как вы и говорили).

1. Слева **Authentication** → **Users** → **Add user** → **Create new user**.
2. Укажите email (любой, реальный не обязателен, например `kassa@shop.local`)
   и пароль.
3. Включите галочку **Auto Confirm User** (иначе Supabase потребует подтверждение
   письмом, которое некуда будет прислать).

## Шаг 4. Забрать ключи и вписать в config.js

1. Слева **Project Settings** (шестерёнка) → **API**.
2. Скопируйте **Project URL** и ключ **anon public** (не `service_role` — тот
   секретный, в браузерный код его вставлять нельзя).
3. Откройте `config.js` в этой папке и впишите оба значения:

```js
window.SHTRIH_KASSA_CONFIG = {
  SUPABASE_URL: "https://xxxxxxxx.supabase.co",
  SUPABASE_ANON_KEY: "eyJhbGciOi...."
};
```

4. Откройте `index.html` прямо в браузере (двойным кликом) — уже должно
   появиться окно входа. Войдите email/паролем из шага 3 и проверьте, что всё
   работает (добавьте товар, отсканируйте/введите штрихкод, сохраните чек).

## Шаг 5. Разместить на Vercel

Проще всего через готовый Node.js, если он у вас установлен:

```bash
cd shtrih-kassa-web
npx vercel login      # один раз откроет браузер для входа/регистрации
npx vercel --prod     # спросит пару вопросов (Enter почти везде) и выдаст ссылку
```

Готово — ссылка вида `https://ваш-проект.vercel.app` и есть ваша касса,
доступная с любого устройства по интернету.

**Без терминала:** зарегистрируйтесь на [vercel.com](https://vercel.com), нажмите
**Add New → Project**, залейте туда эту папку через связанный GitHub-репозиторий
(создайте репозиторий на GitHub, загрузите туда файлы папки, затем в Vercel
выберите **Import** этого репозитория). Vercel сам всё определит — это статические
файлы, настройки сборки не нужны.

## Дальше

- Обновлять цены/товары можно двумя способами: через саму кассу (вкладка
  «Товары») или прямо в Supabase → **Table Editor** → таблица `products` —
  выглядит и работает как обычная таблица, почти как Google Sheets.
- История чеков — там же, таблица `receipts`, поле `items` хранит состав чека.
- Бесплатного тарифа Supabase (500 МБ, без ограничения по количеству строк
  вроде прежнего лимита в 5000) с большим запасом хватит для точки продаж.
- Если понадобится несколько кассиров с раздельным логином, разных
  прав доступа или печать чеков — это отдельные доработки, скажите, сделаем.
